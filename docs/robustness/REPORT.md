# Robustness checks

Generated by `python scripts/run_robustness.py` from the three validated regions (NASA FIRMS standard-processing data; reference scale Aqua MODIS).

## A. Does a calibration transfer between regions?

The calibration fitted in the source region (all of its years) is applied unchanged to the target region and compared with what Aqua MODIS really observed there, month by month. The target region's own result is its held-out (leave-years-out) score, for comparison. Months count only if every day has both the platform and Aqua.

## B. MODIS switched off before and after Aqua's orbit drift
